# Maquettes de la carte personnage

Pistes gardées de côté (non publiées). Pour les ouvrir, les copier dans `site/` et servir le dossier en local :

- `_carte.html` : carte paysage, portrait ou bannière, avec thèmes et choix du contenu.
- `_cartes2.html` : 4 directions (`?d=1` carte à collectionner, retenue ; `?d=2` affiche cinématique ; `?d=3` fiche façon jeu ; `?d=4` portrait dans la goutte).
- `code/` : la version mise en ligne puis retirée (`card.js`, `cards.mjs`, branchement dans `integration-site.diff`).
- `IDEES.md` : toutes les pistes et pourquoi elles ont été écartées.
